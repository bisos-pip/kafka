* Architecture
  - =py3/bisos/kafka/kafkaInfo.py= --- the single source of facts. Everything else
    imports it: pinned versions + checksums (Kafka SHA-512 from Apache, Kafbat SHA-256
    from the GitHub asset digest), paths, banna ports, generators of
    /etc/kafka/server.properties, /etc/default/kafka, /etc/default/kafbat-ui and of the
    units' identity lines, and kvDrift()/unitDrift() for driftCheck.
  - Layout on a host:
    | /opt/kafka/kafka_2.13-4.3.1, /opt/kafka/current -> it | root, read-only     |
    | /opt/kafka/kafbat/api-v1.5.0.jar                      | root               |
    | /etc/kafka/server.properties, /etc/default/kafka{,bat-ui} | root:kafka 640 |
    | /var/lib/kafka/data (KRaft meta + partitions), /var/log/kafka | kafka 750/755 |
  - =py3/bin/=:
    - kafka-cbs.pcs (CBS: sbom + units [kafka, kafbat-ui] + kafka-assemble.cs)
    - cbmProc-kafka.spcs (CBM pointer; leaf sys/cbm/collective/hereWeb/kafka/)
    - kafka-sbom.pcs: apt openjdk-21-jre-headless + curl, then func-bearing pseudo-pkgs
      kafkaAcctSetup, kafkaDistSetup, kafkaConfSetup (writes configs only when absent;
      formats storage only when meta.properties absent), kafbatUiSetup. All idempotent.
    - kafka-sysd.pcs, kafbat-ui-sysd.pcs (both User=kafka, EnvironmentFile=...)
    - kafka-here-dns.pcs, kafka-wvd.pcs, kafka-assemble.cs (hereDns + webVirtDom)
    - kafkaAdmin.cs (hostInfo, servicesInfo, topicsInfo, consumerGroupsInfo,
      driftCheck, fullUpdate), quickKafka.cs (cheat sheet)
  - Ports (bisos.banna tcpPorts.py): kafka=24007 broker, kafkaController=24008,
    kafbatUi=24009. All listeners bind 127.0.0.1.
  - kafka.here -> 127.0.22.113 -> nginx :80 -> proxy_pass 127.0.0.1:24009 (Kafbat UI).

* Key Design Decisions
  - hereWeb (like airflow), not bedrock (like postgres): kafka has a web UI at kafka.here.
  - Upstream binaries, pinned + checksummed, in kafkaInfo: Debian packages neither Kafka
    nor Kafbat UI. Bumping a version means bumping its checksum; a mismatch aborts the sbom.
    Fetched from archive.apache.org (downloads.apache.org keeps only recent releases).
  - Kafbat UI as a plain jar under systemd, no Docker.
  - Loopback-only listeners: Kafbat UI has no authentication. Hence kafka-wvd.pcs proxies to
    kafkaInfo.listenIp (127.0.0.1), NOT socket.gethostbyname(fqdn) as airflow-wvd.pcs does.
  - Single node: every internal-topic replication factor is 1 (stock 3 would leave
    __consumer_offsets uncreatable). controller.quorum.bootstrap.servers, format --standalone.
  - Config files written only when absent (hand overrides survive); kafkaAdmin.cs -i driftCheck
    reports drift instead of overwriting --- same pattern as airflow's /etc/default/airflow.
  - Storage formatted only when meta.properties is absent; checked with =sudo test= because
    dataDir is kafka-owned 750 (a plain [ -f ] by the invoker always sees it missing).
  - kafbat-ui Wants= (not Requires=) kafka.service: the UI stays up while the broker restarts.
  - No ExecStop= on kafka.service: systemd SIGTERM is Kafka's graceful shutdown;
    kafka-server-stop.sh signals every Kafka on the host. SuccessExitStatus=143.
  - nginx vhost written in kafka-wvd.pcs (not webVd_nginxSites.atPortSite) to add
    proxy_buffering off + proxy_http_version 1.1.
  - banna (out-of-chain record: commit 115db49 in bisos-pip/banna, under git):
    /etc/hosts IPs are now stored per port (TcpPortNuInfo.hereIp/hereName) instead of
    derived from sorted position --- the old scheme would have shifted six existing
    .here names by 3 when the kafka ports were added. Existing names keep their IPs;
    kafbatUi carries hereName="kafka"; the broker/controller ports have no .here name;
    _dev ports keep theirs (Mohsen's decision). Import-time check rejects duplicate IP/name.
    tcpPorts.hereIpOf() lets wvd files avoid depending on /etc/hosts being current.
  - The kafka account's uid/gid = 503 come from bisos.banna.sysAccts (banna Stage 3,
    record in banna's AI-WorkPlan.org), not from useradd's auto-selection, so they are
    the same on every platform. kafka-sbom.pcs uses sysAccts.useraddScript(): it creates
    the account with 503 when absent, only warns if an existing kafka account has other
    numbers, and refuses if 503 is held by someone else. bisos.banna's registry range is
    500-999 without touching /etc/login.defs (Mohsen's decision).
